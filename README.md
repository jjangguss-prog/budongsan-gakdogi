# 부동산 각도기

유동성(M2)·수요·공급으로 지금 시장을 진단하고, 시군구 지도로 온기가 어디까지 번졌는지,
하락장에도 거래가 꾸준했던 단지는 어디인지를 위에서 아래로 보는 부동산 시장판입니다.

- 앱으로 설치: 이 저장소의 GitHub Pages 주소를 열고
  - 아이폰: Safari → 공유 → 홈 화면에 추가
  - 안드로이드: Chrome → 메뉴 → 앱 설치(홈 화면에 추가)
  - PC: Chrome·Edge 주소창 오른쪽의 '앱 설치'
- 매일 자동으로 갱신됩니다.
